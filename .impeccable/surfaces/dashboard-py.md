# Audio map

Mode: Operate. Precisely scoped local course demo; no design interview or deployment requested. Code-led, no generated assets.

## Direction contract

THESIS: A laboratory embedding viewer. Audio selection immediately becomes a location and a set of neighbors, not a decorative dashboard of statistics.

OWN-WORLD: Light neutral workbench, system sans, quiet reference dots, blue neighbor circles and an orange query diamond. Thin solid axes, explicit legend, flat sections. Shape and text supplement color. Presenters use this on a laptop and classroom projector under normal room lighting.

STORY: Select a labeled example or upload a recording, listen, locate it, inspect the actual high-dimensional neighbors. Reference examples use stored embeddings and omit themselves from voting; new files use frozen model inference.

FIRST VIEWPORT: Title and model explanation, one compact input column beside a dominant interactive 2D map. Analyze action belongs with audio controls. Query label and links make the new location visible. Results and readable neighbor table follow; narrow screens stack inputs above map.

FORM: Third grounded direction, laboratory embedding viewer; seed 2c6a4411. User's small, explainable browser dashboard brief takes precedence over unrelated catalog-world treatments. Signature interaction: analyzing places an orange diamond on a fixed map, with blue spokes to its 21 original-space neighbors. No entrance animation; native zoom and pan own motion.
